# Verification: consolidate-db-contract-tests

## Assertion map

Every assertion in the six in-scope scripts, with where it goes. Line numbers refer to the scripts as they stand before Phase 4 deletes them.

- **Classes.** **P** = permanent rule of the final schema. **T** = one-time transition or intermediate schema state. **F** = sanity check on the test's own setup.
- **Destinations.** A contract domain file under `scripts/testing/database/contract/`, existing Vitest coverage under `tests/database/`, or "dropped" with a reason. Phase 2 fills the exact domain `file:line` for each row that names only a file.
- **42501 rows.** "Expectation changes to exact 42501" marks a check that passed only because a hand grant masked production privileges. On the final schema it must raise exactly `42501`, and any row it targets must still exist.
- **Vitest + contract rows.** A row with a Vitest anchor and a contract file is kept in the contract test too, because the Vitest suite runs under the local stack's permissive default privileges.
